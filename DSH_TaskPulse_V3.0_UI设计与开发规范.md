# DSH TaskPulse V3.0 UI设计与开发规范

## 1. UI设计目标

设计原则：

-   不干扰DSH主对话
-   小范围入口
-   高信息密度
-   快速发现异常

------------------------------------------------------------------------

# 2. 右上角入口

默认：

    ┌────────────┐
    │ AI任务 8   │
    └────────────┘

规格：

-   宽度：120px
-   高度：32px
-   圆角：12px
-   半透明玻璃效果

------------------------------------------------------------------------

# 3. 展开面板

尺寸：

-   宽度：360px
-   高度：600px

结构：

    AI TaskPulse

    任务统计

    工作区列表

    任务卡片
